# Upwork portfolio entry

## Title
Customer Churn Prediction with Python and scikit-learn

## Role
Data Scientist / Machine Learning Engineer — Personal Project

## Description
Built a reproducible customer churn classification workflow using Python, pandas, and scikit-learn. The project includes data validation, missing-value imputation, categorical encoding, feature scaling, stratified train/test splitting, five-fold cross-validation, and comparison of a baseline model, Logistic Regression, and Random Forest. The selected model is evaluated on a held-out test set using ROC-AUC, precision, recall, F1, balanced accuracy, and average precision. The pipeline saves an inference-ready model, prediction outputs, model comparison reports, confusion matrix, ROC curve, and permutation feature importance. The dataset is deterministic synthetic data created solely for this personal portfolio project.
